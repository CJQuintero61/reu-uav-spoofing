# reu-uav-spoofing
This repo contains the code related to the Summer 2026 Research Experience for Undergraduates (REU).

Included are machine learning (ML) models used to detect UAV GPS spoofing signals.

Authors:
- Lilyanna Yang
- Christian Quintero

## References
